# Rules that each cost something

**Never edit the served tree while a runner lives.** Each new server imports the
tree as it stands. Violated twice; once it produced two JIT build dirs with
different hashes, put the TP ranks on different kernel source, and voided a run
after 7 minutes of zero decode batches.

**A quality draw is the only detector after a selector change.** A purge once made
attention read the trash slot for ten hours while every byte, kept and ITL counter
reproduced. W=16's `+inf` latch did the same with `errs=0`. Counters cannot see
wrong rows.

**Never detect a process by argv pattern.** `pkill -f "sglang.launch_server"`
matched this session's own shell command line and killed it. Read
`/proc/<pid>/cmdline`, skip entries containing `shell-snapshots` and
`compile_worker`.

**Test parameters can make a fault unreachable.** The W=16 device test passed four
invariants and proved nothing: it reused a FIXED score tensor (so the carried
threshold had no dynamics) at G=4096, which equals `kCandMax` exactly and therefore
never spills. Enumerate a kernel's regime switches and land a case in each; check
boundary values specifically.

**Probe in the family that has range.** Two phase probes returned bounded nulls
because niah is 1.000 on both arms, and the second tried to create difficulty with
decoys that do not move what is saturated. Read the per-cell table and pick a cell
with headroom before building.

**Quote both runs of a pair; never interpret a singleton.** The cwe cell's
run-to-run sd is 0.037 (vk) / 0.019 (dsa). Reading two concordant DSA draws as
"tight" was wrong -- the third came in 0.040 lower.

**Never truncate and read a file in one expression.**
`open(p,"w").writelines([... for l in open(p)])` empties it; it once wiped the queue
state record.

**Never bare `git stash` / `git stash pop` in these worktrees** -- the stash stack is
shared with the main checkout and other sessions. Use
`git stash push -u -m "<tag>"`, capture the SHA, `git stash apply <sha>`, then drop
by tag.

**Commit identity is always explicit**, never written to git config:

    git -c user.name=fan-wenjie -c user.email=fanwj@mail.ustc.edu.cn commit ...

**`~/vestigekv_paper` is Gitee: commit, never push.** The GitHub code repos are ours
to push.

**Do not write to a shared mount.** Weights and outputs go under `/home/user`.
